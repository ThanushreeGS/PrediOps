      Safety, security & compliance

      • Tenant isolation: per-tenant raw series are only ever combined into aggregated, rack-level numbers (slope %, growth rate); no tenant's raw telemetry is exposed in another tenant's view.
      • Read-only: every module in this pipeline only reads telemetry and writes forecasts/reports — nothing here can modify power, cooling, or network controls.
      • Audit trail: every forecast run is appended (never overwritten) to audit/forecast_audit_log.jsonl with a hash of its input data window.
